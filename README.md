# Surge Modules

个人维护的 Surge 模块集合，按用途分类存放。

## 网络诊断

### IPPure 节点纯净度

检测指定策略组当前节点的 IP 纯净度、类型、位置与请求延迟。支持在模块参数中填写策略组名称。

- Surge iOS 5.9.0+
- Surge Mac 5.5.0+

安装地址：

```text
https://raw.githubusercontent.com/yixiay/Surge-Modules/main/modules/network-diagnostics/ippure/ippure.sgmodule
```

默认策略组：`✈️ 我的节点（所有订阅）`

源码与说明位于 [`modules/network-diagnostics/ippure`](modules/network-diagnostics/ippure)。
